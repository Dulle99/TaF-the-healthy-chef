# TaF – The Healthy Chef

Full-stack web application for discovering healthy recipes and nutrition-focused blog content.

## Overview
- Originally developed as a university course project for Software Engineering
- Built for students, high-school students, and content authors
- Focused on healthy eating, recipe discovery, and educational blog content

## Problem
Many students and high-school students rely on unhealthy fast food and lack simple tools for finding practical healthy meal ideas.

## Target Users
- Readers: students and high-school students
- Authors: users who publish recipes and blog posts

## Key Features
- User registration and login
- Reader and author roles
- Browse recipes by meal type
- Browse and sort blogs/recipes
- Ratings and comments
- Save content for later
- Track completed recipe steps
- Create, update, and delete recipes/blogs
- Recommendation features

## Tech Stack
- ASP.NET Core Web API
- React
- TypeScript
- Neo4j
- Redis
- Quartz.NET
